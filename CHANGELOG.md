# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-08-26

- Render dropped files and folders as removable attachment chips while keeping serialized paths out of the visible draft.
- Leave image-only and workspace-file drags to their owning DSH plugins.
- Add ungrouped General chat sessions with an enabled composer.
- Add the `dsh-file-drop-resolve` startup-conflict preflight command.
- Harden temporary uploads with loopback, same-origin, size, path, and permission checks.

## 0.1.0 - 2026-08-26

- Add file and folder dropping to the DSH Web composer.
- Add the General chat sidebar entry.
